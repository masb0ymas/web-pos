# Rencana: Membuat PRD Aplikasi POS

**Deliverable:** satu file `docs/PRD.md` berbahasa Indonesia — dokumen kebutuhan lengkap yang menjadi acuan sebelum mulai ngoding. (Pengkodean sendiri akan dilakukan setelah PRD ini Anda review/setujui.)

## Keputusan requirement yang sudah dikonfirmasi
- **Pengguna:** single-user, tanpa login
- **Database:** SQLite via Prisma (file lokal, mudah dibackup)
- **Kasir:** pembayaran Tunai (input bayar + kembalian), QRIS, Kartu; diskon per item & per transaksi; PPN 11% opsional
- **Reporting:** dasar — total pendapatan & jumlah transaksi per periode + daftar transaksi, tanpa grafik

## Struktur PRD yang akan ditulis

1. **Ringkasan Produk** — web POS untuk satu toko, UI bahasa Indonesia, mata uang Rupiah, jalur cepat kasir harian.
2. **Ruang Lingkup** — In scope: dashboard, kelola produk, kasir/transaksi, invoice, laporan dasar, pengaturan toko. Out of scope: login/peran, multi-cabang, manajemen pembelian/supplier, grafik laporan, refund (ditandai kandidat v2).
3. **Tech Stack** — Next.js 16 App Router + React 19 + TypeScript + Tailwind v4 + shadcn/ui, SQLite + Prisma, Server Actions untuk mutasi data.
4. **Kebutuhan Fungsional per Modul:**
   - **Dashboard (`/`)** — ringkasan hari ini (omzet, jumlah transaksi, produk stok rendah) + shortcut ke kasir
   - **Produk (`/produk`)** — CRUD, kategori, SKU unik, harga jual, stok, status aktif/nonaktif, pencarian & filter
   - **Kasir (`/kasir`)** — grid produk + pencarian cepat, keranjang, diskon item/transaksi (nominal/%), toggle PPN 11%, validasi stok & bayar tunai, simpan transaksi atomik (Server Action) + pengurangan stok otomatis
   - **Invoice (`/transaksi/[id]`)** — nomor otomatis `INV-YYYYMMDD-XXXX`, detail item dengan snapshot harga/nama, header toko dari pengaturan, tampilan cetak via print CSS (struk thermal & A4)
   - **Riwayat (`/transaksi`)** — daftar transaksi, filter tanggal & metode bayar
   - **Laporan (`/laporan`)** — filter periode (hari ini/minggu/bulan/custom), total pendapatan, jumlah transaksi, rincian daftar; ekspor CSV sebagai bonus opsional
   - **Pengaturan (`/pengaturan`)** — nama toko, alamat, telepon, pengaturan PPN default
5. **Model Data** — entitas `Category`, `Product`, `Transaction` (invoiceNumber, subtotal, diskon, pajak, total, metode bayar, bayar/kembalian, waktu), `TransactionItem` (snapshot nama & harga produk, qty, diskon), `StoreSetting`. Semua nominal disimpan sebagai integer rupiah.
6. **Struktur Route & Komponen** — peta halaman App Router.
7. **Alur Utama** — alur transaksi kasir langkah demi langkah + aturan bisnis (stok kurang, bayar kurang, nomor invoice unik per hari).
8. **Kebutuhan Non-Fungsional** — desktop/tablet-first, format id-ID (Rupiah & tanggal), keranjang kasir berjalan di client (cepat), state kosong & error yang jelas.
9. **Milestone** — M0 setup+seed → M1 produk → M2 kasir+transaksi+invoice → M3 laporan+dashboard+pengaturan → M4 polish & uji akhir.

Setelah PRD disetujui, file langsung dibuat di `docs/PRD.md` tanpa perubahan kode lain.
